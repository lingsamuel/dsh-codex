# Codex 新会话默认模型与思考强度

## 设置

在 DSH 的「设置 → 通用」中，在默认权限附近增加「新会话默认模型」和「新会话思考强度」。两项复用 DSH 原生设置行，选择即生效。模型菜单列出 Codex 当前配置的提供方下的模型。思考强度菜单始终可见，档位来自当前默认模型。即使模型跟随 Codex，也可以单独选择思考强度。切换模型时使用新模型公布的默认档位，用户可再选其他档位。

默认值随当前 DSH Profile 保存，所有访问该 Profile 的标签页共用。两项选择「跟随 Codex」时完全沿用 Codex 设置。网页设置与 Codex CLI 分别持有各自的偏好。

## 生效规则

新建草稿优先显示输入栏明确选择的模型和思考强度，其次是 DSH Profile 默认值。跟随 Codex 时沿用草稿当前按工作目录读取的默认值，创建线程时由 Codex 按实际启动目录解析配置。打开、编辑草稿仍只读取设置。保存默认值后，已打开且沿用默认值的新草稿也会更新显示。

普通发送、创建目标和开始审查共用现有首次提交入口。Host 在创建线程时应用同一优先级，复用现有 `thread/start` 的提供方、模型和思考强度参数。已经存在的 Codex 会话沿用其原生设置，输入栏临时切换仍只作用于当前会话。首次提交需要重试时沿用已创建线程的设置和回执流程。

保存前按 Codex 目录核对选中的模型和档位。更新失败时继续显示上一次生效的值和失败原因。目录变化后，设置页保留已保存值，用户可以重新选择或恢复「跟随 Codex」。Codex 拒绝启动所选模型时，界面保留草稿并显示原因。

## 验收

- 首次打开设置时两项默认跟随 Codex。模型菜单只列当前提供方，思考强度立即可选。选择后即时生效，刷新页面和重启 Host 均能恢复同一组默认值。
- 对照未发送草稿的显示和实际 `thread/start` 参数，覆盖普通项目及工作树，验证显式草稿选择的优先级。
- 分别从普通发送、创建目标和开始审查进入首次提交。确认既有会话继续使用原生设置，输入栏切换后保存的网页默认值保持原样。
- 恢复「跟随 Codex」后，确认新草稿和首发重新采用工作目录的 Codex 设置。
