# Codex 子智能体活动展示

网页的子智能体菜单优先显示 Codex 保存的当前任务路径，例如 `/root/fork_review`。缺少路径时，依次沿用昵称、角色和会话名。导航使用原生线程 ID。同一个线程当前只有一个路径，Codex 可以替换路径并释放旧路径。

在活动发生的位置显示一行状态，例如「子智能体 /root/fork_review 已完成」。支持启动、完成和中断。复用 DSH 对话时间线的节点扩展，让状态行在轮次过程收起时也可见。点击路径打开子会话，沿用原生导航和面包屑。目录里尚未加载的子会话按线程 ID 只读查找。子会话不可读取时，状态行保留原路径并提示打开失败。

子会话地址保留原生父子线程 ID。DSH 的可继续模式和输入栏遵循 Codex 返回的 `canAcceptDirectInput`，能力未提供时沿用 CLI 对旧版代理路径的判断。会话打开后收到新的原生能力时，同步更新输入和队列入口。允许直接输入时可发消息、对运行中的轮次插话，以及在会话空闲时手动继续待发队列。队列编辑与执行仍由原生接口校验会话状态和归档条件。

实时更新与历史分页共同使用 Codex 的 `subAgentActivity` 条目。活动按原生条目 ID 关联，保留记录中的路径和顺序。分页历史使用原生线程级条目游标发现写到较早轮次的记录，并补回已加载的轮次。旧历史仅展示实际保存的活动。

Codex 的协作等待记录投影到 DSH 原生 `wait_agent` 工具行。折叠时显示等待中、结束或超时的状态，工具结果保留原生子智能体状态和消息。

验收覆盖菜单的路径优先级和兼容回退、活动状态与顺序、刷新及重连时去重、子会话导航，以及轮次过程折叠时的可见性。
