# Codex 后台进程接入 DSH

## 运行版本

项目固定使用 DSH 0.2.3-alpha.2。Profile 加载该版本的认证、会话状态及会话面板插件。构建沿用 DSH 随包发布的文件补全搜索模块。

## 界面

- 使用 DSH 0.2.3-alpha.2 的原生会话面板，在「后台任务」分栏显示当前会话还在运行的 Codex 后台命令及工作目录，按进程提供停止确认操作。面板收起且有后台进程时，标题栏的面板按钮显示蓝点。
- 在 Sidebar 会话行右侧显示终端图标，原生悬停卡片显示运行中的后台进程数。标记在会话轮次空闲时也可出现，无须打开该会话。最后一个进程退出后，分栏、蓝点和侧栏标记随同一份状态更新。
- `/ps` 继续提供快速查看入口，与会话面板共用进程列表读取。Codex 的后台终端列表提供命令、工作目录和进程 ID。本次范围为运行中的进程，面板只呈现可由该接口确认的信息。

## 数据与操作

首个目录连接建立时，Host 立即扫描共享 Codex App Server，此后每轮结束间隔 10 秒自动扫描。Host 分页读取 `thread/loaded/list`，再以有限并发读取各会话的 `thread/backgroundTerminals/list`。所有网页复用这份扫描和快照，通过已有目录流接收变化。最后一个目录连接关闭后停止扫描。使用 Codex 原生线程 ID 关联会话与进程，读取过程无须恢复历史会话或订阅任何轮次。已卸载或暂时无法确认状态的会话不显示运行标记，连接恢复后以新的完整快照重建。

从面板确认停止后，Host 通过 `thread/backgroundTerminals/terminate` 提交该会话和原生进程 ID，立即回读列表以更新三个显示位置。进程刚好自行退出时，以新名册为准。停止失败时保留仍在运行的行并显示反馈。普通轮次的停止操作仍走原生轮次接口。

## 验收

- Codex 会话仍在后台运行命令时，在网页打开其他会话也能看到对应的 Sidebar 图标。当前会话轮次结束后，后台命令仍显示。
- 打开对应的会话面板可看同一批进程和工作目录。确认停止其中一个后，其他进程继续运行。进程自然退出也会更新图标、悬停说明和面板。
- 验证多个网页共用 Host 查询、断线恢复，以及停止和进程自然退出重合的情况。读取后台进程时不改变 CLI 会话的订阅或审批归属。
