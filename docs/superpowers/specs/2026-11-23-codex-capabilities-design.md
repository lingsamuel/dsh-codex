# Codex 能力接入规格

在现有独立 Codex Web Profile 中交付技能、插件和 MCP、Git worktree，以及会话导出。定时任务暂缓。网页继续通过已落盘的原生记录跟随历史。文件树、交互式终端和浏览器沿用现有装配范围。

## 技能、插件和 MCP

- 输入栏按会话工作目录列出 Codex 已启用技能。键入 `$` 可搜索选择，直接键入已知的 `$技能名` 也按同一规则识别。发送和插话保留可见文本，并提交 Codex 原生 `skill` 项。候选、说明和路径以 Codex 返回的目录为准。旧会话可直接查候选和历史。
- 插件页展示已安装插件、当前 Codex 可发现的目录以及插件提供的技能、App 和 MCP 服务。插件详情、安装、卸载和 App 授权沿用 Codex 提供的操作及结果。网页确认后刷新原生状态，CLI 上已有的安装和连接在网页可见。
- MCP 页面展示 Codex 返回的服务、连接和授权状态与工具，提供原生 OAuth 登录和重新加载配置。会话内的 MCP 表单和外部授权请求复用现有待处理交互的生命周期，提交、拒绝或取消时使用原生请求身份。CLI 先处理时网页同步关闭；表单字段仅随该请求提交。
- 复用 DSH 原生输入触发器、设置与面板扩展点、对话交互组件。历史和目录读取沿用现有只读连接；MCP 待处理事项沿用当前会话的按需订阅。用隔离实例验收跨工作目录的技能候选、发送和插话、跨端插件状态，以及 OAuth、表单和 CLI 抢先处理。

## Git worktree

- 在 Git 项目新建会话时可选本地目录、新建 worktree 或已有 worktree。新建可选基准分支，首次提交后为该工作目录启动原生 Codex 会话，仍归入原项目。复用 Git 自己的工作树登记和现有 Codex 新建/续写链路。
- 输入栏复用 DSH 的透明按钮和原生菜单，标记当前选择。本地目录显示实际路径，新建与已有工作树分别展开基准分支和可用目录。已开始的会话从标题栏选择目标，确认后才切换。
- 空闲会话可在同一仓库的本地目录与 worktree 间切换，沿用同一个会话 ID。页面在 Codex 确认新工作目录后刷新文件引用、预览和后续输入的作用域。已有活动轮次、待发消息或后台进程时，切换入口说明需先处理什么。
- 本阶段切换的是会话工作目录。各检出中的未提交改动留在原处，分支和检出由用户自行管理。网页和 CLI 均可继续使用 Codex 确认的会话目录。用含未提交改动的临时 Git 仓库验收检出隔离、工作目录切换、并发提交和失败后重试。

## 会话内搜索

- 标题栏使用透明搜索按钮。弹窗将搜索框放在结果列表上方，结果独立滚动。每条摘要按正文换行，在原位置高亮匹配文本。选择结果后关闭弹窗并定位原消息，末尾提供后续结果。

## 会话导出

- `/export` 和会话操作菜单提供复制 Markdown 和下载 `.md`。从 Codex 读取选中会话的完整已保存历史，按原生顺序导出标题、正文、可见的工具记录和附件说明。在线会话导出已保存部分，归档和未加载会话直接导出。
- 复用当前历史分页和聊天事件转换，以及 DSH 已发布的 Markdown 格式化工具。用包含多页历史、代码块、图片和工具输出的会话验收内容顺序，并核对导出期间原生会话的归档和加载状态。
