# 目录分组转为 Codex 项目

在自动目录分组的原生工作区菜单中提供「转为项目」。一次操作登记所选目录，并将该分组已保存的普通和归档会话纳入项目。同目录已有项目时沿用原有记录。目录分组沿用文件夹图标，已登记项目使用 DSH 的工作区树图标，包括已有项目和本次转换后的项目。

Host 按侧栏的目录归组规则从 Codex 分页读取会话，并复用已有的项目查找与创建流程。只迁移原属该分组的会话，包括归档筛选暂时隐藏的会话。子会话通过现有父子关系访问。用 Codex 原生会话元数据接口更新项目归属，保留会话 ID、历史、归档状态、队列和工作目录。侧栏按原生通知及操作回读更新。

部分会话迁移失败时保留已完成的结果，提示成功与失败数量，并提供重试。重试复用项目，只处理仍在目录分组里的会话。

验收覆盖目录菜单、已登记项目的图标、分页的普通与归档会话、隔离相邻目录和其他项目、项目复用，以及部分失败后重试。
