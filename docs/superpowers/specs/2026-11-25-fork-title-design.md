# 从旧回复分叉时恢复标题

## 设置

「Codex on DSH」在拟标题设置中增加「从旧回复分叉时恢复当时的标题」与「分叉时也回滚手动改名」。两个开关默认开启，按 DSH Profile 保存并自动应用。主开关关闭时分支继承 Codex 原生标题，手动改名开关暂不生效并保留所选值。手动改名开关关闭时，源会话的当前手动标题按原生规则继承，自动标题仍可按轮次恢复。

## 记录与恢复

从新版开始，在现有 Profile 标题记录中保存 DSH 首次拟标题、自动更新及网页手动改名成功后的新旧标题、所属轮次及原来的自动管理状态。手动改名关联到改名时的最新轮次，同名的手动改名也记录管理权变化。后续拟标题的既有注记继续展示其请求与结果。历史注记的显示开关与标题恢复互相独立。

从 DSH 旧回复分叉时，以 Codex 确认复制到分支的轮次为准，撤销所选轮次之后有记录的标题变更。在第 8 轮手动改名时，第 1–7 轮分支恢复旧标题，第 8 轮起分支使用新标题。只通过 Codex 改写新分支的标题。恢复后的自动标题保留自动跟随资格，分支保存再次分叉所需的标题变更。恢复无需请求模型。

侧栏从当前历史头分叉沿用原生标题行为。分叉点未命名、记录与原生标题无法核对、轮次读取失败或原生改名失败时，保留可确认的原生分支结果。外部客户端的改名仍由 Codex 保存和同步。在 DSH 未记录的变更无法按轮次恢复。

## 验收

验证默认值和 Profile 持久化，自动与手动改名的轮次边界，两个开关的交互，未命名分叉点，沿分支再次分叉，以及旧会话和现有拟标题注记的兼容性。
