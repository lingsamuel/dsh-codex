# Codex 账户额度圆环

在 Codex 输入框的模型选择左侧使用 DSH 的右侧工具栏插槽。入口使用独立的图标圆环，参考 ChatGPT Desktop 的额度提示。圆环取最紧张周期的剩余比例。低于 10% 时放大圆环，用 0–10% 刻度和 DSH 警示色绘制弧线，中央只显示数值，例如剩余 4% 时显示「4」。点击入口后，用紧凑浮层逐行显示周期和剩余百分比。悬停、键盘聚焦或点按额度行时显示重置倒计时。入口采用 DSH 的按钮、浮层材质和提示气泡。输入框下方的上下文用量继续由 DSH 自己显示。

复用页面已有的目录 SSE 连接。连接建立后读取 Codex App Server 的账户额度，随后合并普通 Codex 额度的广播。部分原生额度通知只发给轮次所属连接，目录在轮次结束后合并读取。账户变更时清除旧账户读数并重新获取，到达重置时间时重新读取。Host 只传递额度窗口的持续时间、剩余比例和重置时刻。没有窗口可显示时隐藏入口，也支持仅返回周额度的账户。

先用真实 SSE 路由和模拟 Codex daemon 验证初始读数、稀疏广播以及账户切换，再挂接原生插槽和中英文详情。验证构建及窄屏下通过鼠标和键盘查看额度的流程。
