# WSL 历史浏览实施计划（历史记录）

当前实现见 [架构](architecture.md)。

**目标** 在独立的 DSH Profile 中打开并浏览现有 Codex 会话。

**技术栈** Node.js、Codex App Server JSON-RPC、DSH 浏览器插件、React。

1. 先用真实 Unix WebSocket 测试服务器验证握手、分页、错误和连接关闭。实现面向现有 daemon 的只读 API。
2. 装配独立 Profile，使用 DSH 公开的 Fetch 路由和客户端 Slot 注册。复用 Markdown 和代码渲染，按原生项目或工作目录呈现会话。
3. 构建插件，验证真实 daemon 的历史分页和 DSH 浏览器挂载。记录运行方式与当前验证范围。

## 只读功能

首期沿用 Codex 的原生线程、记录和回执，以及 DSH 的搜索、工作区和聊天组件。

- [x] **全局正文搜索**。接入 `thread/search`，将原生摘要和尚未载入的会话送入 DSH 搜索。
- [x] **会话内消息定位**。使用 `thread/searchOccurrences` 定位分页历史中的消息，旧历史仍可由侧栏搜索打开匹配会话。
- [x] **侧栏实时同步**。从同一个 daemon 跟随会话新建、改名、归档、删除、项目归属和项目本身的变化。只更新受影响的目录和会话；切换当前聊天和等候首次目录期间也能跟随侧栏。
- [x] **原生置顶与归档**。读取 Codex Pinned 分组及归档清单，复用侧栏置顶和归档筛选；查阅归档历史时保持其归档状态。
- [x] **子代理会话**。以原生父子线程关系按需展示子代理及状态，复用 DSH 的目录和只读聊天。
- [x] **长对话导航**。复用 DSH 轮次导航，按需读取更早轮次并通过原生 ID 定位。
- [x] **轮次文件改动汇总**。从已保存的 `fileChange` 记录汇总轮次改动，并复用 DSH 文件差异和查看交互。
- [x] **当前模型、推理强度与目标**。显示 Codex 实际返回的当前配置、`/goal` 及进度，保留历史模型信息的原始粒度。
- [x] **后台终端**。通过 `/ps` 按需读取已加载会话的 Codex 后台终端。
- [x] **计划清单**。使用可读的原生结构化计划供 DSH 任务列表展示。Markdown 计划仍由原有聊天视图显示。
- [x] **上下文占用**。Codex 提供已保存的上下文 token 总量和窗口容量时，在输入栏及 `/status` 中显示。
- [x] **文件预览**。识别 Codex 消息中的路径与行号，复用 DSH 的右侧只读文件预览，保持原生会话记录和文件内容。

## 第一阶段会话管理与输入界面

- [x] 网页前台显示当前会话的最新消息后自动标为已读。使用与这份消息一起获取的原生回执版本，避免清除后来完成的回复。会话菜单提供标为未读，并保留本次打开期间主动设置的未读。
- [x] 通过原生 DSH 会话菜单改名、置顶或取消置顶，与 CLI 同步。
- [x] 接入 DSH 原生对话输入界面。发送及轮次控制留待下一阶段。

## 输入栏命令与模型

- [x] 复用 DSH 的「+」命令菜单，提供 `/status`、`/ps`、`/goal` 和 `/rename`。模型设置通过独立选择器提供。
- [x] 模型和推理强度由 Codex 原生目录提供，已加载会话使用 `thread/settings/update` 保存后续轮次的设置。未加载会话的选择随草稿提交。
- [x] 将原会话详情中的信息移到命令菜单和模型选择器，移除标题栏入口。

## 会话归档、删除与历史分支

- [x] 复用 DSH 的归档、取消归档和撤销入口。会话或其子代理正在执行时须确认停止后才归档。删除需要单独确认，沿用 Codex 原生的会话及子代理删除规则。
- [x] 侧栏会话菜单对当前历史头部分支。聊天末尾的原生 DSH 回复操作以该回复所属的已结束轮次为边界，直接通过 `thread/fork` 的 `lastTurnId` 建立新会话，源会话保留原状。
- [x] 在分页会话上用原生 `thread/revert` 回到选定轮次之前。网页需在确认前说明影响，并同步更新聊天、轮次导航和阅读回执。操作限定于已加载且空闲的会话，工作区文件保留。
- [x] 在每轮开头的用户输入旁增加就地编辑，复用 DSH 复制操作行、气泡样式和编辑控件。取消只退出编辑。发送前核对进入编辑时的最新轮次，并在回退后的同一个会话提交修改后的输入，保留原生附件和引用。若发送失败，可复制草稿。

## 回复操作与问答显示

- [x] 将回退放入原生回复操作栏，跟随分支和复制的显隐规则。就地编辑沿用 DSH 编辑控件，在宽屏有独立编辑宽度，在窄屏收缩到聊天列。
- [x] 展示 Codex 保存的异步提问和选项，已提交的答案复用 DSH 只读问答卡。原生阻塞问答通过实时请求交互，0.171.0 的历史接口无法读取独立的问答记录。轮次中途的插话和结构化答复可随整轮回退。
- [x] 已结束轮次按原生轮末判定能否分支，保留最终回复之后属于该轮的工具和子代理记录。历史删除入口明确写明删除本轮及后续对话，在确认时检查历史头和运行状态，并在需要时恢复会话。

## 网页新建、继续与轮次操作

- [x] 从 DSH 原生工作区入口新建 Codex 线程。打开历史走只读连接，首次提交需要运行时的操作时按需恢复。
- [x] 复用 DSH 原生输入栏与忙碌时的 Enter 设置。普通发送与排队写入 Codex 原生队列，空闲时由 Codex 立即开始，运行中等当前轮完成。直接插话用 `turn/steer` 和原生目标轮次 ID。
- [x] 复用 DSH 原生队列显示和操作，保留 Codex 队列 ID。停止用 `turn/interrupt`。暂停的队列保留，用户手动选择继续。跨客户端的队列变动实时回读。
- [x] 在隔离环境验证两端使用同一 App Server、普通发送、插话、停止、排队、旧会话加载及 CLI 对普通审批请求的处理。
- [x] 未加载会话可以直接使用原生输入框。新建入口复用同一工作区的原生空线程和 DSH 草稿，首条消息保存后显示 Codex 预览，刷新时从原生索引和已加载的线程恢复侧栏。
- [x] 正在查看的会话进入原生待答状态时，使用 DSH 的原生问答面板进行普通实时问答。网页和 CLI 可回答同一个请求，由 Codex 确认结束。
- [x] 当最新轮次写入 `agentMessage.questions` 时也显示原生问答面板。异步答复携带原生问题 ID，优先插话到提问所在的运行轮次。原轮次不能接收插话时，经轮次校验后走原生队列。已排队或已保存的答复关闭对应选项。

## 工作区和会话交互接入

- [x] 工作区。原生请求测试和隔离浏览器覆盖项目改名、排序与删除。操作和原生事件刷新同一项目目录。
- [x] 路径引用。候选以原生线程 cwd 为准。隔离浏览器验证原生 `@` 补全及含空格路径的序列化。
- [x] 按需取消归档。验证原生确认、恢复与提交顺序，以及归档移动记录后的历史重连。隔离浏览器验证查看时仍归档、发送时继续原线程。
- [x] 网页审批。验证原始请求身份、决定范围、CLI 并发回应和请求结束。隔离浏览器验证 DSH 原生审批卡及文件详情加载。
- [x] 权限选择。以原生目录和设置确认驱动 DSH 控件。网页默认值只用于新建线程。
