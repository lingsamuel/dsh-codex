# 启动与使用

需要 Node.js 24.9 或更新版本、可在当前 WSL 环境运行的 `dsh`，以及正在运行的 Codex App Server。当前使用 DSH 0.2.2-rc.5 和 Codex App Server 0.171.0 验证。

```sh
npm ci
npm run build
npm start -- --no-open
```

用浏览器打开 DSH 打印的完整启动链接。服务监听 `127.0.0.1:3190`，可通过 `--port` 指定另一个端口。启动链接包含本次运行的 DSH 访问令牌。

升级 DSH 或更新项目的 Profile 配置后，重启项目的 DSH 实例以载入新的插件清单。

在侧栏底部打开「设置」，可以在 DSH 原生「通用」页调整语言、外观和字体等界面偏好。

DSH 原生侧栏显示 Codex 的项目和工作目录。打开页面后，侧栏先显示缓存或已索引的项目，再从 Codex 自动补齐，并实时跟随会话和项目变动。同一个目录的大小写别名使用实际名称。浏览器默认打开一条近期的 Codex 会话。展开工作区可切换会话，从对话顶部可加载更早的轮次。

自动生成的目录工作区按组内最近一条未归档对话的更新时间从新到旧排列。没有可用更新时间的目录排在末尾。Codex 中显式创建的项目沿用项目清单的顺序。

侧栏搜索同时查找标题、工作区和 Codex 的会话正文。正文结果显示 Codex 返回的片段，点击即可打开对应会话。使用分页历史的会话在标题栏提供会话内搜索，点击结果可跳到对应消息。

侧栏会话菜单支持改名、置顶、取消置顶、标为未读、归档、取消归档和永久删除。归档运行中的会话会先确认是否停止当前操作。可通过侧栏「视图选项」显示归档会话，再在归档行选择「查看归档会话」。查看会保留归档状态。永久删除需要确认，会移除该会话及其子代理的历史，工作区文件保留。

侧栏会话菜单的分叉入口复制当前会话历史，并将新的 Codex 会话加入侧栏。已结束轮次的回复下可以选择「在新对话中分支」，直接打开截至该轮的分支。同一轮内在回复之后保存的工具和子代理记录也会随整轮复制。

在已加载且空闲的分页会话中，可以从回复操作栏选择「删除本轮及后续对话」。确认后会移除本轮的提问、回复、工具记录及其后的历史。工作区文件和已执行操作的影响会保留。尚未加载的会话可先从输入框继续。

同一条件下，每轮开头的普通用户消息在「复制」旁提供「编辑消息」。点击后在原位置展开编辑区，取消会恢复原气泡。发送会回退到该轮之前，并在同一个 Codex 会话提交修改后的消息，沿用原生附件和引用。打开编辑器后历史如有变化，请复制草稿并重新打开编辑。回退和重新发送分两步执行，发送发生错误时可复制草稿并核对会话状态。

当前会话收到普通实时问答请求，或 Codex 在最新轮次保存异步提问时，DSH 会自动打开原生答题面板。异步问题会在轮次运行中出现，答复按 Codex 原生格式入队。收起后可用标题栏的问答图标重新打开，CLI 也可回答。要求保密输入的题目和审批在 CLI 处理。已提交的答复继续显示为 DSH 问答卡，并随所属轮次一起回退。

存在子代理的会话在标题栏显示 DSH 子代理菜单。可以展开分支，直接阅读对应的 Codex 子会话，点击标题栏面包屑逐级返回父会话。

长对话可用聊天右缘的轮次导航预览并跳转。较早轮次先显示摘要，选中后才加载对应历史正文。

展开轮次末尾的文件改动汇总，即可查看 Codex 记录的差异，包括同一文件在该轮的多次改动。

输入栏「+」菜单提供 `/status`、`/goal`、`/ps` 和 `/rename`。可以查看会话状态及上下文、当前目标、后台终端，或打开原生改名弹窗。

输入栏右侧可以选择 Codex 原生模型和推理等级。已加载的会话应用选择到后续轮次，包括编辑旧消息后的重发。可以在编辑过程中切换，待输入栏显示新设置后发送。未加载的历史会话显示已保存的设置。

Codex 保存了结构化计划时，聊天底部显示 DSH 的任务清单。普通的 Markdown 计划继续在正文中显示。

点击聊天中的本地文件链接可在 DSH 右侧打开预览。相对路径以原生会话工作目录为准，`file://`、`路径:行号` 与 `#L行号` 链接可定位到对应行。

Codex 回复中的 Visualize 预览会显示在聊天正文里，可以直接操作。宽版预览可用「展开预览」放大查看。预览需要 DSH Host 能读取源文件，并且本机有 Python 3 和 Codex 插件缓存中的 Visualize 渲染脚本。源文件或渲染脚本不可用时，原回复会显示错误原因。

默认通过 `codex app-server daemon version` 查找当前环境中的共享服务。自定义 socket 可设置 `DSH_CHATGPT_SOCKET`，自定义 Codex 或 DSH 可执行文件可分别设置 `DSH_CHATGPT_CODEX_BIN` 和 `DSH_CHATGPT_DSH_BIN`。

侧栏的「新建会话」使用当前工作区目录。再次点击时会优先打开该工作区尚未发送的草稿。首条消息写入后，侧栏显示 Codex 的原生预览，有名称时优先使用名称。首次使用时可以通过「添加工作区」选择目录。打开旧会话可以直接查看历史。将鼠标移到输入框，选择浮层中的「点击继续会话」，Codex 会加载原会话并启用输入。按 Tab 聚焦按钮或使用触屏也可继续。

发送文本使用 DSH 原生输入栏。忙碌时，Enter 和发送按钮使用 DSH 设置里的默认发送方式，Ctrl/⌘+Enter 使用另一种方式。排队消息由 Codex 依序执行，也可在原生队列中编辑、移除或改为插话。点击「停止」会中断当前轮并暂停待发队列。需要恢复时，在队列下点「继续队列」。

打开对话后会实时跟随 Codex 写入的消息和工具记录。DSH 侧栏用转圈表示运行中，用黄点表示等待审批或回复，用绿点表示 Codex 标记为未读。点开会话并在前台看到最新消息后，会自动标为已读。主动标为未读时，绿点保留到下次打开并看到最新消息。标题栏补充连接和异常提示。尚未保存的逐字输出会在 Codex 写入后显示。本地文件附件显示原生引用。
