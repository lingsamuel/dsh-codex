# 安装与使用

在浏览器打开本机 Codex 会话，可以接着处理 CLI 中的任务、翻看历史，或在指定工作目录开始新会话。

## 安装并打开

**安装前**准备 DSH 0.2.3-alpha.2、pnpm 和 Node.js 24.22.3 或更新的 24.x，或 Node.js 26.13.1 及以上版本。运行时需要已登录的 Codex 和正在运行的本机共享 App Server。插件使用 App Server 0.171.0 验证。

如果 Codex 已登录、共享服务尚未启动，可运行 `codex app-server daemon start`。

1. **取得插件包。** 下载 GitHub Actions 中 Build 工作流的 `dsh-chatgpt` artifact，解压得到 `.tgz`。从源码打包时，在仓库根目录运行 `npm ci` 和 `npm run package:plugin`，然后到 `artifacts/` 取包。
2. **安装到 `codex` Profile。** 将示例路径替换为实际包的绝对路径，再启动 DSH。首次安装会创建该 Profile 并注册插件配置。使用自定义 `DSH_HOME` 时，安装和启动都应使用同一目录。

   ```sh
   dsh plugin --profile codex add /absolute/path/to/dsh-chatgpt-0.1.0.tgz
   dsh --profile codex --no-open
   ```

3. **在浏览器打开 DSH 打印的完整链接。** 默认监听 `127.0.0.1:3190`，可用 `--port` 更换端口。完整链接包含本次运行的访问令牌。打开后，侧栏会显示本机 Codex 的工作区和会话。

**更新插件**时，用同一个 `codex` Profile 安装新 `.tgz`，然后重启该实例。首次从源码启动方式迁移时，使用新的持久 `DSH_HOME`，插件会从原有 Codex App Server 读取会话。安装验证和排障见 [给 AI 助手的安装指南](ai-install.md)。

## 打开工作区和会话

### 继续已有会话或开始新会话

- **继续已有会话。** 浏览器默认打开一条近期会话。展开侧栏中的工作区即可切换会话，也可先查看历史和编辑草稿。发送时 Codex 会按需加载原会话。
- **开始新会话。** 侧栏的「新建会话」使用当前工作目录，并优先打开该目录尚未发送的草稿。首次使用时，可通过「添加工作区」选择目录。
- **设置会话标题。** 首条消息写入后，侧栏先显示 Codex 的原生预览。首条消息有正文时，Codex 会额外发起一次模型请求来拟标题，失败时使用正文摘录。也可通过 `/rename` 手动改名。

侧栏会先显示缓存或已索引的项目，再从 Codex 补齐，并随会话和项目变动实时更新。同一目录的大小写别名统一显示为实际目录名。

### 搜索和阅读历史

- **找会话。** 侧栏搜索覆盖会话标题、工作区和正文，遵循「视图选项」中的归档筛选。打开归档搜索结果会保留该会话的归档状态。
- **找消息。** 对话顶部可加载更早的轮次。分页会话可用标题栏的会话内搜索跳到对应消息。长对话可用聊天右缘的轮次导航预览并跳转，较早轮次会先显示摘要，选中后加载正文。
- **读子智能体记录。** 标题栏的子智能体菜单优先显示 Codex 任务路径。点开分支可读子会话，用面包屑返回父会话。对话中的启动、完成和中断记录也可跳转到对应子会话，等待工具行会显示进度和结束状态。

### 管理工作区和会话

- **工作区。** Codex 中显式创建的项目沿用项目清单的顺序，支持改名、删除和拖动排序。删除项目会解除会话的项目归属，保留会话历史和目录文件，侧栏随后按工作目录重新分组。自动生成的目录分组按组内已发送且未归档会话的最近更新时间从新到旧排列，缺少可用时间的目录排在末尾。
- **会话。** 侧栏菜单提供改名、置顶、取消置顶、标为未读、归档和取消归档。手动排序时，打开页面后新建的会话会放在已有置顶会话和普通会话之间。CLI 等其他客户端创建的会话也遵循该规则，断线期间的会话会在重连时补入。浏览器会记住原有会话的相对顺序。
- **永久删除会话。** 侧栏菜单中的「永久删除」会在确认后移除会话及其子智能体的历史，工作区文件会保留。

### 归档与恢复

在「视图选项」中显示归档会话。打开后可以读历史、编辑草稿、选择模型和权限。置顶、取消置顶和拖动排序都会保留归档状态。归档正在运行的会话时，页面会先确认是否停止当前操作。

- **恢复后发送或执行。** 点击「取消归档并发送」或「取消归档并继续队列」，Codex 会恢复原会话并应用所选设置。
- **查看待发队列。** 点击「查看队列」并确认后，网页会取消归档并显示待发消息。可编辑或移除消息，也可点击「继续队列」开始执行。

## 发送消息与跟进执行

### 附加图片和引用文件

- **图片。** 可按 Ctrl/⌘+V 粘贴截图，也可选择或拖入 PNG、JPEG、WebP、GIF 文件。发送前可预览或移除图片，支持单发图片和图文一起发送。
- **路径引用。** 输入 `@` 搜索当前工作目录中的文件或目录。选中的路径随消息发送，由 Codex 按需读取当时的文件内容。

### 排队、插话和停止

会话忙碌时，Enter 和发送按钮使用 DSH 设置中的默认发送方式，Ctrl/⌘+Enter 使用另一种方式。**排队**会等待 Codex 依序执行，**插话**会把消息交给仍在运行的轮次。待发消息可以编辑、移除或改为插话。要修改附图消息的正文，可使用「编辑待发图片消息」。

点击「停止」会中断当前轮次并暂停待发队列。有待发项时，可点「继续队列」恢复。轮次中断且此前没有待发项时，再次发送会启动新轮次。

发送后输入框会立即隐藏已提交的文字。网络失败或超时且尚未确认送达时，输入框会恢复原稿。

### 审批与问答

- **审批。** 当前会话收到请求时，审批卡会显示操作详情和可选决定。网页和 CLI 均可处理，Codex 确认请求结束后卡片会关闭。标题栏的审批入口可查看当前会话的其他待处理请求。
- **问答。** 实时问答或最新轮次中的异步提问会打开答题面板。收起后可从标题栏重新打开，也可在 CLI 回答。要求保密的输入在 CLI 中完成。
- **异步答复。** 默认插入提问所在的运行轮次。若该轮仍是最新轮次，但已结束或暂不能接收插话，答复会进入 Codex 队列。Codex 接收后会显示确认，网页会在对应轮次保留问答卡，回退该轮时也会移除卡片。

如需取消当前操作并修改要求，可选「取消本轮并补充指令」，等本轮结束后在输入栏发送新指令。Codex 提供「不执行并继续」时，可以拒绝该操作并让本轮继续。Codex 已保存的取消调用可在对应历史轮次中展开。

### 跟踪会话和后台任务

打开会话后，网页会实时显示 Codex 已写入的消息和工具记录，逐字输出会在保存后显示。连接状态和异常提示位于标题栏。

| 侧栏标记 | 含义 |
| --- | --- |
| 转圈 | 会话正在运行 |
| 黄点 | 等待审批或答复 |
| 绿点 | Codex 标记为未读 |
| 时间左侧的蓝点 | 会话仍有后台进程 |

打开会话并在前台看到最新消息后，会话会自动标为已读。手动标为未读后，绿点会保留到下次打开并看到最新消息。

悬停带蓝点的会话可查看进程数。在标题栏面板的「后台任务」中，可以查看命令、工作目录，或确认停止特定进程。面板收起时，按钮也会显示蓝点。页面约每 10 秒更新，最后一个进程退出后标记消失。

### 模型、权限和命令

输入栏右侧可选择 Codex 的模型和推理等级。已加载会话将选择应用到后续轮次，未加载会话会在当前页面随草稿保留选择，并在发送或编辑旧消息后重发时应用。

权限选择器显示 Codex 已确认的权限和该会话可用的预设，切换应用于后续轮次。沙箱、审批方式和审批人以 Codex 状态为准。「通用」设置的默认权限只在本网页创建新 Codex 会话时使用，默认跟随 Codex。

未加载会话可以显示上一轮权限。缺少预设名称时，若工作目录和权限规则与上一轮一致，会沿用上一轮记录的沙箱模式。网页新建的空白会话可以在发送首条消息前收到权限确认。重启网页服务前创建的草稿或其他客户端创建的空白会话可能只收到接收回执，此时选择器会先显示预设已提交，待 Codex 记录后再显示实际权限。

输入栏点「+」或输入 `/` 可打开命令菜单。

| 命令 | 用途 |
| --- | --- |
| `/status` | 查看会话状态和上下文占用 |
| `/ps` | 列出后台终端 |
| `/rename` | 打开改名弹窗 |
| `/compact` | 在有历史的空闲会话中压缩上下文 |
| `/review` | 审查未提交改动、相对于指定分支的差异、指定提交，或按自定义要求审查 |
| `/plan` | 为后续轮次选择默认模式或计划模式，确认后可从输入栏查看和退出计划模式 |
| `/goal` | 创建带可选 token 预算的目标，或暂停、恢复和清除现有目标 |

压缩状态和审查结果显示在当前对话中。未加载会话有待发消息时，先处理队列。目标由 Codex 执行并同步状态，归档会话可能需要先点「取消归档并读取目标」。Codex 保存的结构化计划显示在聊天底部的任务清单，普通 Markdown 计划显示在正文中。

## 查看文件、差异和预览

- **文件链接。** 点击聊天中的本地文件链接可在右侧打开预览。相对路径以会话工作目录为准。`file://`、`路径:行号` 和 `#L行号` 链接可以定位到指定行。本地文件附件显示为原生引用。
- **轮次改动。** 展开轮次末尾的文件改动汇总。单个文件会直接显示差异，多个文件会先列出前四个，可点「显示全部」查看其余文件。选择文件后会在聊天中展开它在本轮的差异，包括多次改动。
- **Visualize。** Codex 回复中的交互预览可在正文中操作，宽版可点「展开预览」放大。渲染需要 DSH Host 能读取源文件，并可使用本机的 Python 3 和 Codex 插件缓存中的 Visualize 渲染脚本。所需文件或脚本不可用时，错误原因会显示在原回复中。

## 分支或改写历史

### 保留原对话并新建分支

侧栏的分叉操作会复制当前会话历史，并将新的 Codex 会话加入侧栏。只想从某一轮继续时，可在已结束轮次的回复下选择「在新对话中分支」。分支会复制到该轮结束，包括同一轮内在回复之后保存的工具和子智能体记录。

### 在原会话回退或重发

以下操作适用于空闲或未加载的分页会话。

- **删除本轮及后续对话。** 在回复操作栏选择对应操作并确认。Codex 会按需取消归档并加载原会话，再删除本轮起的历史。工作区文件和已执行操作的影响会保留。有待发消息或历史已变化时，网页会中止操作并提示原因。
- **编辑消息。** 在每轮开头的普通用户消息旁选择「编辑消息」。归档会话也可直接打开编辑器。发送时，Codex 会按需取消归档，回退到该轮之前，再在原会话提交编辑后的消息，沿用原生附件和引用。

如果打开编辑器后历史有变化，可复制草稿并重新打开编辑。回退和发送分两步完成，发送出错时可复制草稿并核对会话状态。

## 设置与源码调试

在侧栏底部打开「设置」，可在 DSH 原生「通用」页调整语言、外观和字体等界面偏好。

从源码启动时，在仓库根目录运行以下命令。源码启动使用仓库内独立的运行目录。升级 DSH 或更新项目的 Profile 配置后，重启实例以载入新的插件清单。

```sh
npm ci
npm run build
npm start -- --no-open
```

插件默认用 `codex app-server daemon version` 查找当前环境中的共享 App Server。自定义 socket 使用 `DSH_CHATGPT_SOCKET`，指定 Codex 可执行文件使用 `DSH_CHATGPT_CODEX_BIN`。源码启动脚本可通过 `DSH_CHATGPT_DSH_BIN` 指定 DSH 可执行文件。
